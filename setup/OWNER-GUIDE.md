# Changing the website (for the owner)

Open **[site address]/editor.html** and enter the passcode. Bookmark it on your phone.

- **Menu**: open a section, change a name, description or price, or set an item to Sold out, Hidden or Draft. Add or remove items and sections.
- **Hours**: set each day's opening and closing time, or mark a day closed.
- **Details and links**: address, phone, and where Order online, Reservations, Gift cards and the rest point.
- **Announcement**: one line across the top of every page. Leave it empty for none.

**Preview** opens the site with your changes, as a phone, tablet or desktop, before anyone else sees them.
**Publish** saves. Every page that shows that fact updates the next time someone loads it.

Each fact lives in one place. Change the closing time once and the header, the home page, the footer and the "open now" line all follow.

Live, day-to-day things stay where they already are: today's prices and sold-out items on Toast, reservations on Yelp.

If something looks wrong, the sheet behind the editor keeps Google's own version history (File > Version history), so any change can be undone.
